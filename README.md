# Filipino Cookbook API

## Description
This project is a RESTful API developed using PHP, Slim Framework, and MySQL. It provides information about Filipino foods, categories, ingredients, and origins.

## Features
- Retrieve Filipino foods
- Retrieve food categories
- Retrieve food origins
- Retrieve ingredients
- Return JSON responses
- Token-based authentication

## Technologies Used
- PHP
- Slim Framework
- MySQL
- Composer
- XAMPP
- Git
- GitHub

## Installation
1. Clone the repository.
2. Run:
   ```bash
   composer install
   ```
3. Import the SQL database.
4. Configure the database connection.
5. Start Apache and MySQL.

## API Endpoints
- GET /api/foods
- GET /api/categories
- GET /api/origins
- GET /api/ingredients
